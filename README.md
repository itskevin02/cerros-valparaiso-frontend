# Cerros de Valparaíso - Frontend

Frontend del Sistema de Gestión de Turismo de los Cerros de Valparaíso.

## Tecnologías

- HTML
- CSS
- JavaScript
- API REST

## Funcionalidades

- Dashboard de ventas
- Resumen de operadores turísticos
- Listado de servicios
- Registro de detalles de reserva
- Edición de detalles
- Eliminación de detalles
- Generación de liquidaciones
- Consulta de auditoría

## API

El frontend se conecta al backend mediante:

http://localhost:3000/api
